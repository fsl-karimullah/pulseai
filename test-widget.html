Halaman Uji Coba Widget PulseAI

Ini adalah simulasi website bisnis Anda. Anda dapat menguji fitur Proactive Chat, Idle Follow-up, dan Upload File di halaman ini.

Petunjuk Instalasi Widget:

  1. Buka halaman Integrasi > Widget Website di dashboard PulseAI Anda.
  2. Salin (Copy) kode script yang berawalan <script src="..."></script>.
  3. Buka file test-widget.html ini menggunakan Text Editor (VS Code / Notepad).
  4. Ganti komentar <!-- PASTE SCRIPT WIDGET ANDA DI SINI --> di bagian bawah file ini dengan kode Anda.
  5. Refresh halaman ini dan lihat widget Anda muncul di pojok kanan bawah!
